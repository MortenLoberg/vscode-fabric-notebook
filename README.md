# Fabric Notebook for VS Code

Open Microsoft Fabric notebook files in VS Code's native Notebook Editor.

This extension is inspired by the [Databricks Notebook](https://marketplace.visualstudio.com/items?itemName=andrewgross.databricks-notebook) extension (not a fork). It aims to provide a similar experience for Fabric notebooks: edit notebook cells in VS Code while keeping the original file format as the source of truth.
